# Data lokal

Aplikasi dapat menyimpan dataset yang diunggah pengguna sebagai `jawa_barat.csv` dan metadata sebagai `jawa_barat_metadata.json` jika kotak simpan lokal dipilih. Jangan menganggap data unggahan sebagai data resmi tanpa memeriksa sumber dan definisi kolom.

Berkas CSV provinsi dapat diletakkan di folder ini dengan nama `jawa_barat.csv` sebagai fallback saat sumber daring tidak tersedia.
